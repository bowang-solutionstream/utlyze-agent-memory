# ADR: local evidence-linked memory baseline

Accepted for this bounded implementation by the native Astra plan on 2026-10-30. This is an engineering choice within the user's memory request, not approval of the proposed wider team workflow.

Use Python standard-library SQLite, exact lookup and deterministic keyword context. Keep versioned product knowledge, append-only observations and inert proposals distinct. Link the unchanged canonical failure helper/store rather than duplicate its records. Runtime data/raw evidence stay outside distributed source and skills.

SQLite supplies local transactions, uniqueness, expected revision checks and crash recovery without a new service/runtime or model calls. The custom contract makes authority status, exact task revision lineage, mandatory obligations and bounded omission behavior explicit. The cost is maintaining a narrow schema/CLI; graph/MCP/semantic features are intentionally absent. Scope filtering is not access control, matching hashes are not authenticated truth, and comparison records do not themselves prove improvement.

Official references inspected 2026-10-30:

- [Gbrain README](https://github.com/garrytan/gbrain/blob/master/README.md) and [memory boundaries](https://github.com/garrytan/gbrain/blob/master/docs/guides/memory-boundaries.md): explicit durable facts/provenance, correction/withdrawal and keyless keyword start; local PGLite/no-embedding mode; Bun 1.4.4+; configured extraction/embedding/synthesis and maintenance have separate effects. Gbrain and Bun were not found on this Mac.
- [Mem0 README](https://github.com/mem0ai/mem0): configurable model-backed memory with local options. Managed benchmark claims do not certify the OSS SDK or this task.
- [Gbrain skill optimization](https://github.com/garrytan/gbrain/blob/master/docs/guides/skillopt.md): a future evaluation/promotion reference, not an optimizer invoked here.

Neither framework is inherently cloud-only. Deferring installation is an inference from this task's narrower offline contract and the available Python/SQLite runtime, not a framework quality verdict. A later adapter should be evaluated on a version-pinned representative corpus and held-out retrieval/recurrence cases, including all operating usage. Hosted disclosure, provider spend, background operation and installed policy changes require their own authority.

Revisit this choice when measured keyword misses, corpus size or cross-process integration warrant an adapter. Preserve original source/evidence identities and canonical case obligations during migration. No measured cost or quality improvement is claimed by this release.
