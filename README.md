# Utlyze agent memory

Private progress and implementation repository for the Utlyze agent-team memory system.

The requested system has two purposes: preserve product objectives and feature context for new sessions, and retain evidence-linked success/failure observations for later workflow improvement.

- [Current status and remaining work](STATUS.md)
- [Agreed agent-team direction](docs/TEAM-PLAN.md)
- [Memory architecture and alternatives](docs/MEMORY-DESIGN.md)

The implementation is undergoing local verification and independent review. This initial commit contains progress notes; a reviewed implementation snapshot will follow. No product knowledge pack, operational database, hosted memory service or global skill has been activated.

Private runtime databases, canonical failure cases, raw evidence, session transcripts and credentials are excluded from this repository.
